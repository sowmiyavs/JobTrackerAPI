# JobTrackerAPI
Practical portfolio project that connects Java, Spring boot and SQL skills . 

**Project Overview**
JobTracker API is designed to simplify job application management by providing REST APIs to maintain application details, company information, job positions, application dates and recruitment statuses.

**Technology stack**
Java
Spring boot
Spring Web
Spring Data JPA
Hibernate
MySQL
Maven
Swagger / openAPI
Junit5
Postman
Git&Github

**Project Modules**
Add job application
View job application
Update job status
Delete application
Search applications
